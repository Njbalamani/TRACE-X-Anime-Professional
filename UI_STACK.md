# TRACE-X UI / UX Stack

TRACE-X stays on Django + server-rendered HTML. The visual layer uses progressive enhancement:

- **AOS** — scroll/reveal animations
- **GSAP** — dashboard hero parallax and ambient motion
- **Motion for JavaScript** — small hover interactions without React
- **LottieFiles** — integrity verification micro-animation
- **Uiverse-inspired CSS** — button/hover treatment implemented locally
- **Animista-inspired CSS** — local entrance animation utilities
- **21st.dev-inspired hero composition** — recreated natively for Django instead of importing React/Tailwind components
- **Spline-ready** — a Spline scene can be added later with `<spline-viewer>` without changing the backend
